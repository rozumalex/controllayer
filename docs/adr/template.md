## Context

What problem do we have, and what forces it? Write the facts that hold today, such as constraints, deadlines and what the code does now, so a reader who joins later understands why a choice had to be made.

## Decision

What we do, in one or two sentences that start with "We". Then the details that matter: where it lives in the code and how to use it.

## Alternatives

The other options we looked at, each with the reason we did not pick it.

- **Option:** why not.

## Consequences

What changes after this decision, good and bad: what gets easier, what gets harder, and what we must now remember or keep in sync.
